# 模板：多维并行评审 + 独立校准（review-panel）

**适用**：高风险、跨专业、有可核对原始材料的方案/计划评审。

**为什么**：单一评审者会漏维度、夸大严重性、把环境问题写成计划事实。多维度独立产出 + 另一角色校准严重性，能把“意见”压成“证据”。

## 输入

- 被评审材料（只读，路径固定）；
- 3~5 个评审维度（如产品 / 技术 / 风险 / 合规 / 进度）；
- 每条结论的格式要求：`claim + severity + reason + evidence{path, line_start, line_end, quote}`。

## 步骤

1. **拆维度**：每个维度只关注自己的问题，互不代劳。
2. **并行产出**：每维度独立会话，必须引用原文行号与原文引用，禁止空泛评价。
3. **机器校验**：路径存在、行号在范围内、引文与对应行一致；不合格直接打回。
4. **独立复核**：另一会话读取三路结论与**原始材料**（不是执行者摘要），逐条确认/降级/待验证。
5. **校准严重性**：给出下调理由；重复问题归并为根因，避免重复计数。
6. **回写交付物**：用户确认后，把采纳的修订合并回主文件，并注明哪些结论仍未验证。

## 验收

- 每条结论都有可定位证据；
- 复核至少抽查高影响结论，并给出确认/降级/分歧；
- 报告区分“已证实 / 待验证 / 分歧”，不把推断写成事实。

## 常见失败

- 只有一路评审，没有校准 → 严重性系统性偏高；
- 复核只看摘要 → 共享执行者盲区；
- 证据锚点不校验 → 结论无法追溯。
